# AI Agent 学习工作台（16 周 / 112 天）

这是本地运行、无第三方前端依赖的学习网页。包含 8 个核心模块、12 个补充专题、逐日资料链接、知识点分析、动手任务、费曼学习五步、学习笔记、每日反馈、周报、进度和 DeepSeek 助教。

## 最快开始：无 AI 模式

直接双击 `index.html`。**不用安装任何东西**即可浏览 112 天课程、打开资料链接、记笔记、勾选完成进度、查看每周和整体总结以及导出/导入备份。

网页本地记录保存在当前浏览器的 localStorage；不同浏览器或网址（例如直接双击文件与 http://127.0.0.1:8765）会有不同存储空间。首次从离线文件切换到本地服务前，请先在离线网页中「备份记录」，然后到本地服务网页中「导入记录」。请经常点右上角「备份记录」导出 JSON，再保存到你自己控制的位置。

## 使用 DeepSeek 学习助教（推荐）

本机 Mac 需要 Python 3（macOS 终端中运行 `python3 --version` 检查）。无需安装 pip 依赖。

1. 解压 ZIP，打开「终端」，进入解压后的文件夹（若 Finder 生成同名文件夹则按下面示例）：

   ```bash
   cd ~/Downloads/AI_Agent_112_Day_Learning_Workspace
   ```

2. 在终端输入以下命令，然后按回车；终端会等待你输入 DeepSeek API Key，不显示密钥内容：

   ```bash
   read -s DEEPSEEK_API_KEY
   export DEEPSEEK_API_KEY
   python3 server.py
   ```

   **不要把自己的 API Key 粘贴到网页代码或聊天笔记里。** `read -s` 在 bash / zsh 中可关闭输入回显；密钥仅在当前终端进程的环境变量中使用。请不要将密钥或带密钥的启动命令放进公开仓库。中止服务后，建议关闭该终端会话。

3. 使用浏览器打开：http://127.0.0.1:8765

4. 右侧「DeepSeek 学习助教」状态应显示 **AI 服务已连接**。选择 `deepseek-flash`（默认）或 `deepseek-v4-pro`，然后使用「解释概念」「费曼点评」「苏格拉底提问」「排错」「周总结」「下一步计划」。

5. 使用完成后在终端按 `Ctrl+C` 停止服务。

### 为什么不用浏览器直接放 API Key？

直接在浏览器页面里保存 API Key 容易被网页脚本、插件或错误发布暴露；还可能因跨域策略使调用失败。这里使用 `server.py` 在本机 `127.0.0.1` 提供 API 代理，密钥不发送到浏览器。

代理调用 DeepSeek 官方 Chat Completions API：`https://api.deepseek.com/chat/completions`，官方模型名默认是 `deepseek-flash`，可选 `deepseek-v4-pro`。服务只转发用户明确点击时的学习上下文，默认不发送个人笔记；**费曼点评模式会发送填写的费曼复述**，如勾选「附上当前日笔记与总结」，则还会发送所选笔记。API 提供商会处理实际发送的数据，应以其当期条款为准。

> 重要：不要在学习数据、费曼笔记、DeepSeek 问题和演示中放真实儿童、家长、员工的身份信息、联系方式、健康资料、密码或 API Key。课程里的 EEC 例子仅用于学习，不能作为法规合规结论。

## 功能说明

- **每日学习**：112 天的目标、知识分析、精选资料链接、任务、交付成果、费曼五步、总结、问题与信心评分。
- **进度算法**：必须完成「资料学习」「实践练习」「复盘验证」三项，并写至少一段学习总结，才算完成当日。
- **周总结**：本周七天状态、学习时长、理解信心、成果、常见误区、下一周改进、YouTube 素材。
- **总览**：16 周完成率、已记录的学习时间、每周交付项目。
- **资料库**：40 个课程、官方文档、API、n8n、SQL、Docker、安全、EEC 和认证链接。
- **AI 反馈**：仅按用户请求发送，API Key 不放在浏览器。本日最后 25 条 AI 辅导反馈存在本地，可追加选定回复到总结。
- **安全备份**：右上角导出 JSON；导入时会覆盖当前本地记录。AI 回复和笔记也包含在备份里，请保管好。
